# 实时字幕

把课堂语音实时转成中英双语字幕，全部在本机运行。

麦克风收到的话变成两栏并排的字幕。面向中英互译的学习场景，内置 9 个学科的热词表。

[English](README.md) | **中文**

---

## 功能

**双语实时字幕** —— 左边原文、右边译文。说话过程中先出灰色草稿，说完整句才落成正式双语行。

**双向翻译** —— 中文→英文或英文→中文，随时切换。**界面语言跟着方向走**：中文→EN 用中文界面，EN→中文 用英文界面。

**9 个内置学科热词组** —— 中医、计算机、数学、物理、化学、生物、经济、法律、医学，每组 60~490 个中英词，让识别引擎更倾向于把这些词听对。

**自定义热词组** —— 自己建、自己命名，顶栏下拉随时切换。

**术语助手** —— 右侧面板，回答翻译和术语问题，也能按你的要求增删热词。

**同音纠错** —— 识别把术语听成同音字时（肝阳上亢 → 肝阳上抗），用拼音把字改回来再翻译。

## 界面

```
┌──────────────────────────────────────────────────────────────────┐
│ 实时字幕 [中文→EN│EN→中文]   预设▾ + ⋯  开始  ▮ 未连接              │
├───────────────────────────────────────────┬──────────────────────┤
│  原文 原句原文              译文 翻译结果    │  术语助手            │
│  ──────────────────────────────────────    │  ┌────────────────┐  │
│  原文 原句原文              译文 翻译结果    │  │ 问：什么是…     │  │
│                                           │  │ 答：…           │  │
│                                           │  └────────────────┘  │
│  ┌ 正在识别的草稿 ─────────────────────┐   │  [ 问术语或译法… ]   │
├───────────────────────────────────────────┴──────────────────────┤
│ 空格 开始 / 停止　　字幕保留在本页，刷新即清空                       │
└──────────────────────────────────────────────────────────────────┘
```

- **顶栏** —— 翻译方向、热词组、开始/停止、麦克风电平、状态
- **字幕区** —— 已定稿的句对，最新的在下面；底部灰字是正在识别的内容
- **右侧面板** —— 术语助手，拖中间分隔条可调宽（240~720px）

## 环境要求

- Windows 10/11
- Python 3.10+
- 麦克风
- API 密钥：[火山引擎](https://console.volcengine.com/speech/new/setting/apikeys)（识别）、[OpenAI](https://platform.openai.com/api-keys)（翻译）、[DeepSeek](https://platform.deepseek.com/api_keys)（助手，可选）

## 安装

### 1. Python

装 [Python 3.10+](https://www.python.org/downloads/)，或者运行 `.setup/install_python.py`——不需要管理员权限。

### 2. 配置密钥

两种方式，任选其一。

**在界面里填**（推荐）。点左上角的齿轮，把密钥粘进去保存。会存在本机的 `data/settings.json`。

**环境变量**（开发时方便）：

```powershell
[Environment]::SetEnvironmentVariable("VOLC_API_KEY",     "你的key", "User")
[Environment]::SetEnvironmentVariable("OPENAI_API_KEY",   "你的key", "User")
[Environment]::SetEnvironmentVariable("DEEPSEEK_API_KEY", "你的key", "User")
```

界面里填的优先。两边都没有时，点「开始」会在顶部弹提示，并给一个直达设置的入口。

### 3. 启动

双击 **`run.bat`**。

如果电脑上没有 Python，它会先自动下载一份便携版（约 15 MB，不需要管理员权限），再建虚拟环境、装依赖。浏览器会在几秒后自动打开——这个窗口要留着，关掉它就等于停止服务。

首次运行需要联网。除此之外不需要预先装任何东西。

## 使用

1. 在顶栏**选方向** —— 中文→EN 或 EN→中文
2. **选热词组** —— 默认是中医，学科不同就切
3. **点开始**，允许麦克风
4. 说话。灰色草稿实时出现，说完整句落成双语对
5. 有疑问就**问右侧助手**

任意位置按空格可以开始/停止（在助手输入框里打字时除外）。

## 热词组

内置 9 个。每组由两个方向共用——中文词和英文词存在同一组里，识别时只取与当前方向匹配的那些。

**新建** —— 点顶栏的 `+`，输入名字即可，新组自动选中。

**管理** —— 点 `⋯` 可以改名或删除，至少要保留一个。

**加词** —— 直接跟助手说「把链表和 hash table 加进热词」，或者 `POST /hotwords` 传 `{"add": ["链表"]}`。

改动**下次点「开始」时生效**，因为热词是在识别连接建立时一次性传给引擎的。

## 术语助手

右侧面板只回答翻译和术语两类问题，其他话题会礼貌拒绝。它能在你要求下真的改热词——说「把太阳伤寒加进热词」，它会调用工具而不是嘴上答应。

记得最近几轮对话，所以「刚才问的那个词，加进去」这种指代也认得。

## 常见问题

**点开始没反应 / 没有麦克风**

地址必须是 `127.0.0.1` 或 `localhost`。局域网 IP 会被浏览器静默拒绝——只有安全上下文才给麦克风。

**有灰色文字但没有正式字幕**

识别在工作，分句还没触发。识别引擎在静音约 800ms 后、或输出句号时结束一句。说话时自然停顿即可。

**有字幕但没有译文**

看后端窗口或 `logs/app.log`。常见是 OpenAI 密钥失效或额度用尽——此时会降级为只显示原文，不会中断。

**术语老是听错**

确认当前热词组覆盖了你的学科，以及词的语言与方向匹配（中文→EN 需要中文词）。在日志里搜 `[纠字]` 看同音纠错有没有触发。

**页面打得开但点什么都没反应**

按 F12 看控制台。JavaScript 在加载时报错的话，页面看起来正常但所有控件都是死的。

├── server.py          FastAPI 入口、WebSocket 桥接、/chat 与 /presets 接口

docs/                  实现文档
